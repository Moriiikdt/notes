最长公共子序列

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n = len(word1)
        m = len(word2)

        @cache
        def dfs(i, j):
            # 全去掉
            if i < 0:
                return j + 1
            if j < 0:
                return i + 1
            # 都一致就没有操作 
            if word1[i] == word2[j]:
                return dfs(i-1, j-1)
            # 不一致，也就是其余情况就是+1
            return min(dfs(i-1, j), dfs(i, j-1), dfs(i-1, j-1)) + 1 
        return dfs(n-1, m-1)
```

LIS 最长递增子序列

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        
        @cache
        def dfs(i):
            res = 0
            for j in range(i):
                if nums[j] < nums[i]:
                    res = max(res, dfs(j))
            # 加上本身的i
            return res + 1
        ans = 0
        for i in range(n):
            ans = max(ans, dfs(i))
        
        return ans
```
